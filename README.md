# Bluestock Mutual Fund Analytics Capstone

## Project Overview
This project is developed as part of the Bluestock Fintech Internship.

## Objective
To build an ETL pipeline that loads mutual fund datasets, validates them, fetches live NAV data from mfapi.in, and prepares data for analytics and dashboard development.

## Technologies Used
- Python
- Pandas
- NumPy
- Requests
- SQLAlchemy
- Jupyter Notebook
- Power BI
